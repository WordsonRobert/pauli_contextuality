### `transfer`
**TR-1 (transfer, group version).** If a group `H` of permutations maps lines to lines and is transitive on the lines of `C`, and every translate of the sub-family `L` meets every violated set in at least `d` lines, then `|L(C)|·d ≤ |L|·deg C`, i.e. `d/|L| ≤ deg C/|L(C)|`.
```lean
theorem transfer (C : Config α) (H : Subgroup (Equiv.Perm α)) [Fintype H]
    (L : Finset (Finset α)) (hL : L ⊆ C.lines)
    (hmap : ∀ g ∈ H, ∀ l ∈ C.lines, l.map g.toEmbedding ∈ C.lines)
    (htrans : ∀ l ∈ C.lines, ∀ l' ∈ C.lines, ∃ g ∈ H, l.map g.toEmbedding = l')
    (d : ℕ) (hdeg : ∀ g ∈ H, ∀ s : α → F, d ≤ (C.violated s ∩ imgL g L).card) :
    C.lines.card * d ≤ L.card * C.deg
```

### `transfer_cover`
The counting data behind TR-1: under a line-transitive group every line lies in the same number `c > 0` of translates of `L`, and `|H|·|L| = c·|L(C)|`.
```lean
theorem transfer_cover (C : Config α) (H : Subgroup (Equiv.Perm α)) [Fintype H]
    (L : Finset (Finset α)) (hL : L ⊆ C.lines) (hne : L.Nonempty)
    (hmap : ∀ g ∈ H, ∀ l ∈ C.lines, l.map g.toEmbedding ∈ C.lines)
    (htrans : ∀ l ∈ C.lines, ∀ l' ∈ C.lines, ∃ g ∈ H, l.map g.toEmbedding = l') :
    ∃ c, 0 < c ∧ (∀ l ∈ C.lines, (Finset.univ.filter (fun g : H => l ∈ imgL g L)).card = c) ∧
      Fintype.card H * L.card = c * C.lines.card
```

### `transfer_rigid`
